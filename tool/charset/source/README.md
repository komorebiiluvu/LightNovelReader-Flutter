# Charset mapping sources

These files are the pinned source inputs for `tool/charset/generate_tables.dart`.
They are copied from the WHATWG Encoding Standard on 2026-09-18 and retain the
source identifier and date in their headers.

* `index-gb18030.txt` — two-byte GBK/GB18030 index.
* `index-gb18030-ranges.txt` — GB18030 four-byte pointer ranges.

The standard is published under CC BY 4.0. Portions incorporated into source
code are identified by the standard as BSD-3-Clause. The generated Dart file
records both source hashes, the source identifiers, and the fixed generation
parameters. Generated project code follows the repository's project-source
terms. Updating either input requires a provenance, license, and generated-diff
review.
